## 2026-11-22 21:20 UTC — баг на устройстве: модель не загружалась, исправлено

Пользователь поставил APK, импортировал Qwen3-4B и получил «Could not load …».
Причина: в APK стояло `extractNativeLibs=false`, библиотеки `libggml-cpu-*.so` не
распаковывались на диск, а llama.cpp ищет бэкенды по пути к файлам — в итоге ни
одного бэкенда. Твой `run.sh` этого поймать не мог: там бэкенд слинкован статически.

Исправлено в этом коммите: библиотеки распаковываются при установке, а при ошибке
загрузки приложение показывает текст причины от llama.cpp.

**Задание:** когда соберётся этот коммит, положи его APK в
`/sdcard/Download/ModulAI.apk` и скажи пользователю переустановить. В отчёт запиши
только sha артефакта.

## 2026-11-22 21:25 UTC — второй баг на устройстве: вылет в начале генерации, исправлено

После прошлого исправления модель загрузилась, но приложение упало в начале
генерации. Причина: сжатие кода в release-сборке (R8) переименовало метод
`PieceCallback.onPiece`, который нативный код ищет по имени; `GetMethodID` вернул
null, дальше вызов по нулевому методу. В `run.sh` этого нет: там обычная JVM без R8.

Исправлено: правило, запрещающее трогать этот метод; нативный код проверяет
результат поиска; в CI добавлен `tools/check-apk.sh`, который проверяет собранный
APK на обе найденные сегодня проблемы.

**Задание то же:** APK этого коммита — в `/sdcard/Download/ModulAI.apk`, сказать
пользователю переустановить, записать sha. APK прошлого коммита (21:20) ставить
не нужно, он падает.
